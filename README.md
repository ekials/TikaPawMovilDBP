# TikaPaw Móvil

Aplicación móvil del sistema TikaPaw para refugios y adopción de mascotas.

## Descripción
App móvil conectada a la misma base de datos de la plataforma web TikaPaw.  
Permite gestionar y consultar información de animalitos en refugios y el proceso de adopción.
- Dart / Flutter
- Base de datos compartida con la versión web
